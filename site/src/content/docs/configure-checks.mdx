Add the sections below to `sprawl-guard.toml` at the repository root.

## Select source files

Enable each language under `[languages.<id>]`. Language IDs are case-insensitive; use
`sprawl-guard languages` to see accepted keys and built-in globs.

```toml title="sprawl-guard.toml"
[languages.rust]
enabled = true

[languages.typescript]
enabled = true
include = ["src/**/*.ts"]
exclude = ["src/generated/**"]
```

`[files].exclude` removes paths before language classification. Each language's `include` and
`exclude` globs then determine which files it owns. Avoid overlapping includes: a file matched by
more than one enabled language is ambiguous.

## Set limits and classify tests

```toml title="sprawl-guard.toml"
[limits.max_lines_per_file]
code_non_test = 400
code = 800

[limits.max_leaf_files_per_directory]
production = 8
test = "unlimited"

[tests]
check_path_tests = true
globs = ["tests/**", "**/*.test.*"]
```

Global and language-specific test globs classify whole files as test code. Test files use the
`code` and `test` limits; production files use `code_non_test` and `production`. Setting
`check_path_tests` to `false` omits path-classified tests. For production Rust files, Sprawl Guard
can also exclude top-level `cfg(test)` items from the non-test line count.

## Add overrides

Overrides apply in declaration order. Each matching override changes only the limit fields it
sets, so a later match wins for those fields.

```toml title="sprawl-guard.toml"
[[overrides]]
paths = ["src/legacy/**"]
max_lines_per_file = { code_non_test = 1000 }
reason = "Legacy subsystem"

[[overrides]]
paths = ["src/legacy/small/**"]
max_lines_per_file = { code_non_test = 500 }
reason = "Smaller legacy modules"
```
