---
title: Clean up violations
description: Lower or remove recorded ceilings as the source tree improves.
---

import { Steps } from "@astrojs/starlight/components";

After reducing a violation, update the ratchet to preserve the improvement.

The commands below use `sprawl-guard` directly. For a project-local Node dependency, run them
through `npm exec -- sprawl-guard` or `pnpm exec sprawl-guard` instead.

<Steps>

1. Improve the source tree.

   Read the failure and note the path, measurement, configured limit, and ratchet ceiling. Split an oversized file, reorganize a directory with too many files, correct an unexpected classification, or adjust a limit only when the policy itself is wrong.

2. Preview the ratchet update.

   ```sh
   sprawl-guard ratchet path/to/improved/source
   ```

   If the measurement is still above its configured limit, its ceiling should decrease to the new measurement. If it now satisfies the limit or is no longer measured, its entry should disappear.

3. Write the update and recheck the repository.

   ```sh
   sprawl-guard ratchet path/to/improved/source --write
   sprawl-guard check
   ```

   Commit the source and ratchet changes together. The lower ceiling prevents the violation from returning to its previous size.

</Steps>

If the preview is surprising, use `sprawl-guard explain PATH` and
`sprawl-guard config resolved`, then consult
[how checks work](/sprawl-guard/reference/how-checks-work/).
