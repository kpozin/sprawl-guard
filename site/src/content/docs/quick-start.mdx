## Choose an installation

Install `sprawl-guard` with Cargo or npm (or pnpm, etc.). The examples below use Cargo's default
user-wide installation and project-local npm and pnpm installations. The Node package requires
Node.js 22 or newer. npm and pnpm can also install the package globally; after a global install,
use `sprawl-guard` directly. A project-local dev dependency keeps the selected version in the
manifest and lockfile.

<Tabs syncKey="package-manager">
  <TabItem label="Cargo">

```sh
cargo install sprawl-guard
sprawl-guard --version
```

  </TabItem>
  <TabItem label="npm">

```sh
npm install --save-dev @kpozin/sprawl-guard
npm exec -- sprawl-guard --version
```

  </TabItem>
  <TabItem label="pnpm">

```sh
pnpm add --save-dev @kpozin/sprawl-guard
pnpm exec sprawl-guard --version
```

  </TabItem>
</Tabs>

All three installations provide the same CLI. `-V` is the short form of `--version`.

## Create the configuration

From the repository root, inspect what Sprawl Guard detects:

<Tabs syncKey="package-manager">
  <TabItem label="Cargo">

```sh
sprawl-guard languages --detected
```

  </TabItem>
  <TabItem label="npm">

```sh
npm exec -- sprawl-guard languages --detected
```

  </TabItem>
  <TabItem label="pnpm">

```sh
pnpm exec sprawl-guard languages --detected
```

  </TabItem>
</Tabs>

Preview the configuration and advisory scan, then write `sprawl-guard.toml`:

<Tabs syncKey="package-manager">
  <TabItem label="Cargo">

```sh
sprawl-guard init --dry-run
sprawl-guard init
```

  </TabItem>
  <TabItem label="npm">

```sh
npm exec -- sprawl-guard init --dry-run
npm exec -- sprawl-guard init
```

  </TabItem>
  <TabItem label="pnpm">

```sh
pnpm exec sprawl-guard init --dry-run
pnpm exec sprawl-guard init
```

  </TabItem>
</Tabs>

To select languages explicitly, use `init --languages python,go` or `init --all-languages`.

## Run the check

<Tabs syncKey="package-manager">
  <TabItem label="Cargo">

```sh
sprawl-guard check
```

  </TabItem>
  <TabItem label="npm">

```sh
npm exec -- sprawl-guard check
```

  </TabItem>
  <TabItem label="pnpm">

```sh
pnpm exec sprawl-guard check
```

  </TabItem>
</Tabs>

A passing check prints:

```text
No sprawl-guard violations found.
```

A file-limit failure looks like:

```text
File size budget exceeded:

  src/large.py
    language: Python
    code lines: 430 / 400
```

Exit code `0` means that the check passed. Exit code `1` means that one or more limits or ratchet
rules failed; the output names each path, measurement, and limit. Exit code `2` reports an
operational error such as invalid configuration or unreadable input.

If the check passes, [add it to CI](/sprawl-guard/run-in-ci/). If an existing repository fails,
[record its existing violations](/sprawl-guard/adopt-existing-repository/).
