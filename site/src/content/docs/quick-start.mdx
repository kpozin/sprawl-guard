Install `sprawl-guard` with Cargo or as a project-local npm or pnpm development dependency. The
Node package requires Node.js 22 or newer.

<Tabs syncKey="package-manager">
  <TabItem label="Cargo">

```sh
cargo install sprawl-guard
sprawl-guard --version
```

  </TabItem>

  <TabItem label="npm">

```sh
npm install --save-dev @kpozin/sprawl-guard
npm exec -- sprawl-guard --version
```

  </TabItem>

  <TabItem label="pnpm">

```sh
pnpm add --save-dev @kpozin/sprawl-guard
pnpm exec sprawl-guard --version
```

  </TabItem>
</Tabs>

All installations provide the same CLI. The steps below use `sprawl-guard` directly. For a
project-local Node dependency, run it through `npm exec -- sprawl-guard` or
`pnpm exec sprawl-guard` instead.

<Steps>

1. Preview the configuration, then write `sprawl-guard.toml`.

   ```sh title="Initialize a repository"
   sprawl-guard init
   sprawl-guard init --write
   ```

   `init` previews the configuration that `init --write` creates. Neither command scans the
   repository.

   The generated root configuration starts with its editor schema and required schema version:

   ```toml title="sprawl-guard.toml"
   #:schema https://kpozin.github.io/sprawl-guard/schemas/v2/sprawl-guard.schema.json
   schema_version = 2
   ```

2. Inspect the detected languages.

   ```sh
   sprawl-guard languages --detected
   ```

   This lists the languages that claim files in the repository and how many source files each
   claims.

3. Run the first check.

   ```sh title="Run the first check"
   sprawl-guard check
   ```

   A passing check prints:

   ```text
   Configuration: sprawl-guard.toml

   No sprawl-guard violations found.
   Checked 2 source files in 2 directories across 2 languages.
   ```

   A file-limit failure looks like:

   ```text
   Configuration: sprawl-guard.toml

   Files over the line limit:

     src/large.py: 430 lines (limit 400)
       language: Python, counting code
   ```

</Steps>

Exit code `0` means that the check passed. Exit code `1` means that the check found violations;
the output names each path, measurement, and limit. Exit code `2` means an error such as invalid
configuration or an unreadable path.

If the check passes, [add it to CI](/sprawl-guard/run-in-ci/). If the check fails on an existing
repository, [record its existing violations](/sprawl-guard/adopt-existing-repository/).
