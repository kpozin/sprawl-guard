# Contributing

Use the issue tracker to report problems or propose changes.

## Report An Issue

- Open an issue for a bug, false positive, feature request, or packaging problem.
- Include the `sprawl-guard` version, your platform, and a minimal reproduction when possible.

## Pull Requests

Pull requests are not accepted. Use an issue to propose a change or report a problem.

See [Development](docs/DEVELOPMENT.md) to build and test the project from source.
