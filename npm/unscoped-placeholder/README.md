# sprawl-guard

This package is a placeholder and contains no code. It reserves the unscoped name on the public npm
registry, so that a lookup of `sprawl-guard` there finds no one else's package. Sprawl Guard is
published as
[`@kpozin/sprawl-guard`](https://www.npmjs.com/package/@kpozin/sprawl-guard):

```sh
npm install --save-dev --save-exact @kpozin/sprawl-guard
npm exec -- @kpozin/sprawl-guard check
```

See the [documentation](https://kpozin.github.io/sprawl-guard/).
